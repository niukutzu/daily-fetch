# 任务：升级「黎明简报」左栏搜索

只改 `build_site.py` 和 `web/index.html`，其他文件不要动。不要新增依赖、构建工具或框架，网页保持单文件、原生 JS。

## 背景

- `build_site.py` 把 `reports/<bot>/<日期>.md`（有的还带同名 `.json`，叫“结构化报告”，`rich: true`）生成到 `site/`。
- 结构化报告的每条情报在 `site/r/<id>.json` 的 `items` 数组里，字段有 `id, source, category, title_zh, title_en, intro, url` 等。
- 非结构化报告只有 `site/r/<id>.html`。
- 现在左栏搜索框 `#q` 只在 `renderSide()` 里筛选 Bot 列表，而且只看得到 `data.json` 里每份报告的前 5 条。

## 要做的事

### 1. 生成搜索索引 `site/search.json`（改 build_site.py）

每条情报一行，所有历史报告都放进去，按日期从新到旧排：

```json
{"r": "tech-2026-11-24", "b": "tech", "d": "2026-11-24", "i": 20,
 "t": "中文标题", "e": "英文标题(可空)", "x": "简介", "s": "来源名", "c": "分类"}
```

- 结构化报告：从 `.json` 的 `items` 取，`i` 用该条的 `id`，`t`=title_zh，`e`=title_en，`x`=intro，`s`=source，`c`=category。
- 非结构化报告：把 markdown 正文里每个列表项（`- ` / `* ` / `1. ` 开头）当一条，`i` 用从 0 开始的序号，`t` 用列表项里加粗或链接文字（没有就用前 40 字），`x` 用其余文字，去掉 markdown 符号。
- 字段为空就省略，减小体积。用 `separators=(",",":")` 紧凑输出。
- `data.json` 不变。

### 2. 搜索规则（web/index.html）

- 不区分大小写（中英文都用 `toLowerCase()`）。
- 输入按空格（半角或全角）拆成多个词；**每个词都必须出现**在 `t + e + x + s + c` 拼起来的文字里才算命中。
- 输入框为空时，恢复原来的 Bot 列表，行为和现在完全一样。
- `search.json` 只在用户**第一次在 #q 输入时**才 fetch，加载完缓存在内存；加载期间显示「正在加载索引…」。
- 输入防抖 150ms。

### 3. 结果显示（替换左栏 #bots 的内容）

- 顶部一行灰色小字：「找到 N 条」；N=0 时显示原来的「没有找到「xxx」」。
- 如果有 Bot 名字包含关键词，先列出这些 Bot（沿用现有 `.row` 样式，点了照旧进入该 Bot）。
- 下面是情报结果，最多先显示 50 条，底部放一个「再显示 50 条」按钮。
- 每条结果三行：
  1. 小头像（复用现有 `av()`，尺寸 20px）+ Bot 名 + 日期（用现有 `rel()`）
  2. 标题，单行省略
  3. 简介里关键词附近的片段（关键词前后各约 30 字，两头加「…」），最多两行
- 第 2、3 行里每个命中的词用 `<mark>` 包起来，样式：`background:transparent;color:#fdba74;font-weight:600`。
- **注意防注入**：先 `esc()` 再加 `<mark>`，不能把原文当 HTML 插入。
- 手机和电脑都要好看，沿用现有颜色变量。

### 4. 点击结果

- 调用现有 `openRep(r)` 打开那份报告。
- 报告渲染完后：
  - 结构化报告：先把报告里的分类/来源/关键词筛选重置为“全部”（`R._f`），给表格每行 `<tr>` 加 `data-iid="${i.id}"`，找到 `data-iid == i` 的行，`scrollIntoView({block:"center"})`，并加一个 2 秒后淡出的高亮（背景 `rgba(251,146,60,.18)`）。
  - 非结构化报告：在报告正文里找第一个文字包含第一个关键词的 `li` 或 `p`，同样滚动 + 高亮。
- 手机上（`narrow()`）点击后要切到报告画面。

## 完成标准（自测）

1. `python3 build_site.py` 无报错，生成 `site/search.json`。
2. `python3 -m http.server -d site` 打开网页：
   - 搜「openai」和「OpenAI」结果相同；
   - 搜「英伟达 CEO」只出现同时含两个词的条目；
   - 搜一个只在报告正文深处出现的词也能找到（不只是前 5 条）；
   - 点结果能打开报告、滚到那条并高亮；
   - 清空搜索框恢复 Bot 列表；
   - 浏览器宽度 390px 时也正常。
3. 不要修改与搜索无关的功能和样式。
